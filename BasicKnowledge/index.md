# 计算机专业基础知识地图

> 这部分内容不要求一次学完，也不直接对应招新分数。它的作用是帮助刚开始接触计算机的同学知道“先学什么、为什么学、学到什么程度可以进入下一步”。

## 1️⃣ 计算机与程序基础

先理解计算机由哪些部分组成、程序怎样运行、操作系统和文件系统负责什么，再建立“输入、处理、输出”的基本认识。

[进入计算机与程序基础](./computer-basics.md)

## 2️⃣ 编程与开发工具

认识编辑器、终端、编译器和调试工具，学会创建文件、运行程序、查看报错和修改代码。工具不需要一次学全，够用之后再逐步扩展。

[进入编程与开发工具](./tools.md)

## 3️⃣ Markdown 与学习记录

Markdown 适合写学习笔记、项目说明和招新题记录。重点不是排版技巧，而是把“做了什么、为什么这样做、遇到什么问题”清楚地留下来。

[进入 Markdown 与学习记录](./markdown.md)

## 4️⃣ Git 与代码协作

Git 用来保存代码版本、查看修改记录和与别人协作。先掌握仓库、提交、分支和远程同步，就足够支撑大部分课程与项目。

[进入 Git 与代码协作](./git.md)

## 5️⃣ 搜索、提问与 AI

学习怎样搜索报错、组织问题、判断资料是否可靠，以及怎样使用 AI 帮助理解而不是替代思考。

[进入搜索、提问与 AI](./search-and-ai.md)

## 6️⃣ 学习方法与节奏

了解如何安排每周时间、拆解陌生问题、记录学习过程，并在课程、项目和竞赛之间保持可持续的节奏。

[进入学习方法与节奏](./learning-guide.md)

## 学习顺序建议

对零基础同学来说，可以先完成“计算机基础、开发工具、Markdown”，再进入 Git 和搜索/AI。已经有编程经验的同学可以直接从自己薄弱的部分开始，不必机械地从头学完。

这些内容属于长期能力建设。招新期间不需要全部掌握，能够理解基本概念、完成小练习并记录过程，就已经达到很好的起点。
