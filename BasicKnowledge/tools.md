# 编程与开发工具

写代码不只等于“打开编辑器输入几行文字”。一个完整的开发过程通常包括创建文件、编辑代码、运行程序、查看结果、定位错误和保存版本。

## 编辑器与 IDE

编辑器主要负责编写代码，IDE 则在编辑器的基础上集成了运行、调试、依赖管理和项目导航等能力。刚开始不需要纠结哪一个“最好”，选择自己看得懂、能稳定运行的工具即可。

选择工具时重点看三件事：

- 是否支持你正在学习的语言。
- 能否清楚显示文件和行号。
- 遇到错误时，能否查看报错位置和调用信息。

工具本身不会替你理解代码。先学会使用基本功能，再根据需要安装插件或更换开发环境。

## 终端和命令行

终端允许你通过文本命令完成进入目录、创建文件、运行程序和查看输出等操作。它看起来不如图形界面直观，但命令可以记录、复现和自动化，因此在开发中非常常见。

可以先熟悉这些操作：

- 查看当前目录。
- 进入、创建和删除目录。
- 查看文件内容。
- 运行脚本或程序。
- 查看命令返回的报错。

## 运行和调试

第一次运行程序时，报错是非常正常的。调试不是“直接猜哪里错了”，而是通过缩小范围、增加输出和逐步验证来找到原因。

可以使用以下顺序：

1. 阅读完整报错，找到文件和行号。
2. 确认程序实际运行到了哪一步。
3. 缩小到可以稳定复现问题的最小代码。
4. 一次只改一个地方，观察结果是否变化。

## 开发环境

不同语言需要不同的运行环境。例如 C/C++ 需要编译器和链接器，Python 需要解释器，Java 需要 JDK。环境配置失败通常不是能力问题，而是版本、路径或权限设置出现了差异。

配置环境时，建议记录：

- 操作系统和版本。
- 安装的软件版本。
- 修改过的环境变量。
- 成功运行的命令。
- 报错原文和解决方法。

## Linux 与远程环境

很多服务器使用 Linux，因此了解基本目录结构、包管理器和 SSH 会很有帮助。初学阶段可以先把 Linux 当作一个可以练习命令行和部署项目的环境，不需要一开始深入研究内核。

如果暂时不使用 Linux，也可以先在 Windows 或 macOS 的终端中完成基础练习，后续再通过 WSL、虚拟机或云服务器补充经验。
