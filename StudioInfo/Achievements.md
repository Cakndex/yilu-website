## 我们的比赛方向

工作室成员参与的比赛覆盖 Web 应用、人工智能、计算机设计、网络技术、服务外包和创新创业等方向。不同比赛对能力的要求并不一样：

- 有的比赛更看重项目完整度和应用价值。
- 有的比赛更强调工程实现、系统设计和现场答辩。
- 有的比赛需要长期积累算法、模型和实验能力。
- 有的比赛需要把技术和产品、运营、展示结合起来。

招新进入工作室后，可以先了解不同比赛的节奏，再根据自己的方向和兴趣寻找队友。我们不承诺“保证获奖”，但会尽量让成员更早接触到真实比赛的信息、规则和协作方式。

## 成员内推与机会分享

工作室成员分布在前后端、机器学习等不同方向，也会在群内分享实习、校招、内推和项目机会。目前已出现过以下类型的信息：

| 分享类型 | 相关信息 |
| --- | --- |
| 校园招聘内推 | 腾讯校园招聘、腾讯混元 AI Infra 等方向的内推信息 |
| 秋招内推 | 字节跳动相关岗位与内推跟进信息 |
| 应届生与实习生招聘 | 米哈游 2027 校园招聘、应届生和实习生专项信息 |
| 竞赛与活动 | 腾讯云黑客松游戏开发挑战赛等赛事通知 |
| 老师项目 | 视频平台、信息统计、访问控制等方向的外部开发需求 |

内推二维码、邀请码和具体联系人信息会随时间变化，因此不直接发布在公开页面。招新群中会同步当前仍然有效的信息。

内推不等于录用，比赛参与也不等于一定获奖。我们能够提供的是信息、经验和一起尝试的机会，最终结果仍取决于项目本身、团队协作和你愿意投入的时间。

## 加入之后会得到什么

你可以把工作室理解成一个比班级群更关注技术实践的协作空间：

- 在比赛开始前了解往届经验和选题方向。
- 在项目卡住时找到可以讨论问题的人。
- 在准备实习和校招时看到成员分享的信息。
- 在课程学习之外，尝试把知识变成真正运行的作品。

如果你对某个方向还没有完全确定，也可以在学习和交流过程中继续探索。最重要的是先迈出第一步，然后保持稳定的投入。
