# 基础-01 Java 入门、变量与流程控制

- **分类：** 基础题
- **难度：** 入门

## 本节知识点

- JDK、IDEA 和第一个 Java 程序
- 注释、字面量、变量和数据类型
- 键盘录入、算术运算和类型转换
- `if`、`switch`、`for`、`while`
- `break`、`continue` 和循环嵌套

## 题目要求

完成一个命令行菜单程序 `NumberTool`，使用 `Scanner` 读取整数，至少实现以下三个功能：

1. 判断一个整数是奇数还是偶数。
2. 输入正整数 `n`，计算并输出 `1 + 2 + ... + n`。
3. 输入一个年份，判断它是否为闰年。

程序需要反复显示菜单，直到用户输入 `0` 退出；每个功能必须单独封装成方法，不能在 `main` 方法中直接写完全部逻辑。

建议菜单格式：

```text
1. 判断奇偶
2. 计算 1 到 n 的和
3. 判断闰年
0. 退出
请选择：
```

## 实现要求

- 至少使用一次 `if` 或 `switch` 完成菜单选择。
- 使用循环让程序可以连续处理多个输入。
- 使用至少三个自定义方法完成具体计算。
- 代码中加入必要注释，变量名能够表达用途。
- 在项目中提供简单的运行说明。
- 记录本题学习笔记，笔记内容不作其他限制，但开头需要回答本题的全部“必答问题”。

## 必答问题

1. JDK、JRE 和 JVM 分别负责什么？
2. 基本数据类型和引用数据类型有什么区别？
3. `break` 和 `continue` 在循环中的作用有什么不同？
