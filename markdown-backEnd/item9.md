- JWT 的生成与校验

- 密码哈希
- 受保护接口

## 接口要求

### 注册

```http
POST /api/auth/register
```

请求体包含用户名和密码。注册时需要检查用户名是否已经存在，密码必须经过哈希后保存。

### 登录

```http
POST /api/auth/login
```

登录成功后返回 JWT，响应示例：

```json
{
  "token": "<jwt-token>"
}
```

### 当前用户

```http
GET /api/me
Authorization: Bearer <jwt-token>
```

只有携带有效 JWT 的请求可以访问，返回当前用户的基本信息。

## 实现要求

- 不允许明文保存密码。
- JWT 密钥需要从环境变量或外部配置读取。
- 使用 Filter 完成受保护接口的令牌检查。
- 未登录或令牌无效时返回 401。
- 已登录但没有权限时返回 403。
