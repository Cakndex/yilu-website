# 基础-03 面向对象基础

- **分类：** 基础题
- **难度：** 入门

## 本节知识点

- 类和对象
- 成员变量和成员方法
- 封装、`private` 和访问方法
- `this` 关键字
- 构造方法和对象初始化
- 对象的内存分配
- `static`、`final` 和枚举

## 题目要求

设计一个 `Student` 类，包含以下内容：

- 私有字段：`studentId`、`name`、`score`、`status`。
- `status` 使用枚举 `StudentStatus`，至少包含 `STUDYING` 和 `GRADUATED`。
- 使用构造方法初始化学生信息。
- 使用公有的读取和修改方法访问私有字段。
- 使用静态变量记录程序创建过的学生对象数量。
- 使用 `static final` 定义一个工作室名称常量。

创建至少三个学生对象，分别输出学生信息、当前对象数量和工作室名称，并演示修改其中一个学生的成绩和状态。

## 实现要求

- 所有字段必须使用 `private` 修饰。
- 构造方法中需要给静态对象数量加一。
- 静态成员和实例成员要在代码中同时出现。
- 记录本题学习笔记，笔记内容不作其他限制，但开头需要回答本题的全部“必答问题”。

## 必答问题

1. 类和对象是什么关系？
2. `this` 解决了什么问题？
3. 静态成员和实例成员有什么区别？
4. `final` 修饰变量、方法和类时分别意味着什么？
