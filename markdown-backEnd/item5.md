## 题目要求

设计一个图形计算程序，至少包含以下结构：

1. 定义接口 `Shape`，包含 `area()`、`perimeter()` 和 `type()` 三个方法。
2. 定义抽象类 `AbstractShape`，实现 `Shape` 接口，并保存图形名称。
3. 实现 `Rectangle`、`Circle` 和 `Triangle` 三个具体图形类。
4. 使用 `Shape[]` 保存多个不同图形，并通过统一循环输出每个图形的类型、面积和周长。
5. 使用匿名内部类创建一个只使用一次的特殊图形对象。

建议的核心接口：

```java
public interface Shape {
    double area();
    double perimeter();
    String type();
}
```

## 实现要求

- `Rectangle`、`Circle` 和 `Triangle` 必须继承 `AbstractShape`。
- 子类构造方法需要使用 `super(...)` 初始化父类部分。
- 在主程序中只能通过 `Shape` 类型调用通用方法，不能分别判断每个子类再计算。
- 匿名内部类需要重写接口中的三个方法，并给出实际可计算的结果。
- 记录本题学习笔记，笔记内容不作其他限制，但开头需要回答本题的全部“必答问题”。
